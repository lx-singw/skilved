# Sprint workflow

- At the end of each completed sprint, run the checks appropriate to the changes, commit the sprint's changes, and push to `main`, unless the user directs a different branch or workflow.
- When accessing this WSL checkout from Windows, invoke Linux Git in `/home/lx_singw/projects/skilved` through WSL. Windows Git reports misleading line-ending and mode changes.
- Keep credentials, local environment files, source snapshots, provider responses and private evaluation artifacts out of commits. `.artifacts/` remains private and ignored.
- Report the commit, push result, verification and any remaining material limitations when closing a sprint.
