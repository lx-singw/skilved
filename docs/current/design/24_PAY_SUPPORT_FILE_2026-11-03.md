# Pay and support file

Implemented: 3 November 2026.

Pay and support now has a dedicated notice-file presentation. Six category-specific headings introduce the funding, learning, trade, placement, programme or employment context. Each numbered entry keeps its benefit kind, source state, amount/range, recorded maximum when present, currency, period and coverage together. Eight benefit kinds have their own existing icon-language treatment. The paper corner, category colour and ruled terms connect this section with the rest of the opportunity workspace.

Stated entries display their own numbers and units. Missing amount and missing currency are separate cases: a recorded number remains visible when currency is unknown, with the missing currency explicitly labelled. Coverage can be absent or multiline without being shortened. The shared amount formatter now uses up to 21 significant digits rather than a 20-decimal-place limit, preserving tiny positive canonical numbers instead of displaying zero. It performs no currency conversion, period conversion, summation, award estimate or cost assessment.

Ambiguous, conflicting and not-stated entries retain distinct states and original wording. They do not expose residual structured benefit values as established facts. Missing entries do not imply that support is unavailable or guaranteed. The existing prompts to consider recurring costs and confirm unclear coverage/payment conditions with the issuer remain, using the notice's own contact details.

Each native disclosure contains that entry's complete original wording and unique resolved source references. References from another entry or the wider listing are not substituted. Missing wording and missing references are explicit. Source links identify their hostname and open separately with the existing privacy/isolation relationship attributes. A separate link leads to the evidence checks; a fact's stated state or reference count is not presented as an overall verification result.

The expanded feed brief now links each support entry to its visible, keyboard-focusable heading in the full notice. Links retain the existing canonical return filters/cursor and use the current entry order. They do not open a source disclosure automatically, acknowledge a revision or record personal progress. The existing `funding-heading` target remains visible and focusable. No production route, API, storage or application action was added.
