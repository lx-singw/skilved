# Opportunity cards and detail workspace

Completed: 1 November 2026.

The anonymous feed now presents each opportunity as a compact information card. Category colours, geometric marks and category-specific actions distinguish the six pathways while retaining the sage and forest theme.

Cards show issuer initials (not an organisation logo), calendar dates without inferred urgency, location and attendance, stated support and amounts, and source-stated entry stages. The expandable brief retains connected requirements and original support wording. Reference counts describe available sources, not verification.

The detail page contains a category overview, links to unresolved facts, numbered navigation, a requirement route map, temporary review progress, the existing browser-local personal workspace, and expandable source evidence. The desktop application panel stays alongside the reading column; on smaller screens it moves above the reading sections. Long card titles use the full phone width.

AND, OR and conditional requirement relationships remain intact. Checklist ticks indicate instructions reviewed, not eligibility, completion or submission. Source-specific checks and original wording remain available. Application handoff, publication boundaries and local save semantics are unchanged.

Verification: typecheck and lint passed; production build passed; all 174 web tests passed, including six new checks for uncertain facts, dates, numeric support and nested requirement branches. Browser review covered inline briefs, review/clear controls, detail navigation, category treatments and phone layout. The isolated local preview uses six explicitly fictional examples; it is not a production deployment.

Remaining limitations: real published records determine how rich the facts are. Unknown information remains explicit. Saves remain browser-local and checklist ticks remain temporary. No user study or retention result is claimed. Preview artifacts remain private and ignored.
