# Instruction details and preparation inspection

Implemented: 3 November 2026.

Each preparation instruction now has its own inspection drawer alongside a kind label and the count of available source references. The drawer sits outside the review checkbox label, so inspecting details or following a source does not toggle the reading tick. Original instruction wording remains primary and preserves line breaks. The existing required/preferred/unclear strength, connected AND/OR/conditional wording, temporary tick count and revision-bound reset remain in place.

Stated qualification values expose designation, the recorded level, completion status and subject thresholds. Provisional and in-progress statuses stay distinct from completed; missing completion, levels and thresholds remain explicit. Zero and fractional percentages are retained without rounding, and an unspecified subject threshold is not treated as zero. A numeric level is labelled generically rather than inventing a qualification framework.

Stated document values expose the document kind, the stage given in the notice, certification wording, format and an exact byte limit. Missing fields remain Not stated in this entry rather than implying no certification, any format or unlimited size. Byte limits keep their exact integer value, including the singular one-byte case. Document stage is distinct from the user's Saved stage. Qualification and document details can coexist when both are recorded, regardless of the instruction's kind label.

Ambiguous, conflicting and absent facts do not produce structured qualification or document assertions. A differing recorded description is shown separately from the original wording. Each source list resolves only that instruction's public citation IDs, deduplicating references in recorded order without borrowing another instruction's sources. Unavailable references are stated plainly. The detail page now passes its public citations into the checklist; callers without references retain the unavailable state. No public schema, extraction value, application method or backend write flow was changed.

Every drawer has an accessible instruction-specific name and a native keyboard-operable summary. Its footer returns to the visible connected-route map. Nested source and subject lists are styled separately from the outer instruction cards. Long names and source text wrap without truncation; mobile detail rows become one column. The new component adds no upload control, eligibility assessment, persistent preparation data or submission action.

Verification passed: all 278 web tests, typecheck, lint and production build. Nine new tests cover all categories and internship routes, provisional/in-progress completion, zero/fractional/missing thresholds, document fields and exact byte limits, combined qualification/document values, fact-specific citation ordering and scope, uncertain/residual values, escaped long Unicode wording, real projection of pending facts, checkbox-label separation and temporary tick/clear behaviour. Existing preparation tests now use the shared UI loader and retain their connected-logic, privacy and bounded-report assertions. A strengthened full-detail source assertion passed its focused rerun and checks that citations actually reach an instruction drawer through the page.

Browser review on the fictional graduate programme confirmed that opening drawers leaves the reading count at zero. Ticking one instruction set it to one of two; opening another drawer preserved that count; Clear these ticks restored zero. The public programme's sparse qualification/document values were not filled in by inference. A separate ignored display fixture exercised provisional qualifications, long multilingual designation text, exact thresholds, document stage/format/size, missing certification, conflicting sources and absent details.

At a measured 389 CSS-pixel viewport, the four open fixture drawers had document scroll width equal to the 370-pixel client width and no horizontal overflow. Detail rows used a single column and each drawer summary measured 44 pixels high. Returning to the route map changed only the fragment and preserved zero reviewed. The temporary viewport override was reset. The desktop fixture was visually reviewed and a complete marked fictional screenshot saved outside the repository.

The display fixture is confined to ignored .artifacts files and does not update the underlying programme record. Browser checks used only temporary reading ticks, which were cleared; no application, saved stage change, report, suggestion, file upload or outbound source visit was performed. Richer fields display only where public reviewed data records them; production data coverage, production deployment and broader user research were not verified in this sprint.
