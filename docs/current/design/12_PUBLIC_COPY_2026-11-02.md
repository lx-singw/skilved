# Public copy and return journey

Implemented: 2 November 2026.

The take-away controls now form a public-copy panel with a primary preview action, separate copy/download choices, and native disclosures for sharing and copy limits. The entry in the personal workspace explains that it keeps instructions, source references and a way back to the notice.

Prepared output has a document presentation: full selectable text, filename, measured UTF-8 size, a complete-selection control, and the canonical public return link. Source wording remains plain text. Conditions and alternatives are not parsed into a simplified checklist. The file itself retains its preparation timestamp and existing limits.

A reference-only result receives its own heading, description and contents label. It does not retain the former title, instructions or application destination. Each subsequent preview, copy, download or sharing intent still performs the existing fresh public read. Pagehide, pageshow, unmount and obsolete reads preserve the existing lifecycle protections.

Clipboard requests now have a three-second deadline. If a request is not confirmed, the fresh preview remains available for manual selection and the action session can accept a later intent. No new personal persistence or application action was introduced.
