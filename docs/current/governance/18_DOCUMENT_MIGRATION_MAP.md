## Preservation and authority

The archive contains exact copies of 70 pre-refresh files: 68 Markdown documents and the root README/CLAUDE context, with original paths, byte counts and SHA-256 manifest. Historical ideas remain available; contradictory plans are no longer presented as current instructions. Twenty-one previously empty documentation files now provide a decision and a usable route into current specifications.

Current discipline documents under `docs/current` are authoritative planning specifications. The root README and documentation index introduce them; legacy filenames are compatibility references. Dated audits and the first-paid-pilot kit retain their substantive content with an explicit status note. Original code and uncommitted implementation work are outside this refresh.

The complete review combines the supplied conversation/attachment, prior documentation audits, selective static code inspection and dated primary-source research. It does not represent a live cloud audit, application test run, legal opinion, customer interview study or executed partnership. Private relationship details and household records are deliberately excluded from public project documentation.
