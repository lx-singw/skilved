## Reusable development tool

From the repository root, `pnpm --filter @skilved/catalogue inventory:source-exposure --root ../../.artifacts/groq --out ../../.artifacts/groq/<sprint>/source-exposure-inventory.json --exclude <sprint> --exclude gemini-quota-state.json` enumerates the actual archive recursively. Paths are relative to the catalogue package, where pnpm runs the script. It records relative evidence paths, file hashes, scope/exclusions, completeness, limits and an archive fingerprint. It does not emit source text or provider replies. Output is exclusively created with private permissions and must be outside the scan or within an explicitly excluded output directory; existing output is not overwritten.

JSON candidates, snapshots, content hashes and retrieval evidence, plus canonical archived detail HTML, establish source-body exposure. A mere listing link remains `link_only`; a URL absent from a complete archive is `not_recorded`. Neither label establishes independence from all human knowledge or material outside the declared archive. Incomplete scans, unreadable/invalid data, symlinks and reached limits make unknown exposure stay `unknown`. Already established source exposure remains visible even when another archive file is unreadable. Bounded evidence samples always retain a source-evidence reference when one exists.

Before generation, `verifySourceExposureInventory` re-enumerates the declared archive and rejects additions, deletions or changed files. A model evaluation must bind its selection to the complete frozen inventory, record prior link/body/model exposure separately where known, and retain failed admissions. Exclude only the new evaluation's output and unrelated mutable metadata; do not exclude older experiments to establish eligibility. This is offline evaluation support; it is not a worker source-admission rule, model-default change or publication feature.
