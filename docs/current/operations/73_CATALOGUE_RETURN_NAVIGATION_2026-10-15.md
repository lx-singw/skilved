# Catalogue return navigation and changed-results recovery

Date: 15 October 2026. Base: `0857776`. Completed local B04a navigation packet; formal B04/G2 remains open.

Feed title and detail links now carry a bounded public catalogue query context. The detail page's Back to results link returns to the same filters, page size and cursor, with a stable anchor identifying the clicked card. The context survives a full detail reload and is retained on the neutral under-review/unavailable landing page. Direct detail links without context retain the All opportunities fallback.

Return context is untrusted input. Only the canonical catalogue path and validated read-query fields are accepted. External destinations, other paths, fragments, control/backslash characters, duplicate context values, duplicate or unsupported filters, private receipt fields and oversized input fall back to `/`. IDs use the canonical ID validator. Navigation uses no arbitrary history redirect, cookies or browser storage; this does not implement B05 saving. Existing browser Back continues to use normal browser/Next navigation behavior.
