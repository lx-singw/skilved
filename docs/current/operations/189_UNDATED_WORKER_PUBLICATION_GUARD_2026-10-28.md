# Undated worker publication guard

28 October 2026 (SAST). Undated RecentJobs worker assessments are private-only: their limited review windows do not establish that applications are open. Manual publication and its read-only preview now reject an identifiable worker-derived draft without a stated calendar closing date, including ambiguous and open-until-filled deadlines. This applies to both fresh and expired assessments; it does not renew or reconstruct a worker decision.

The guard recognizes the existing worker record ID derived from the source ID and original notice URL, using its saved snapshot. It checks current citations and the worker snapshot referenced by the draft's private queue ID. An operator cannot replace that queue ID through `saveDraft` while the original snapshot identifies it as a worker record. This preserves the binding if a later review replaces the discovery citation or the source's current policy changes. Publication and restoration are blocked; withholding and withdrawal remain available. An unrelated manually created record, or a worker record with a stated calendar date, retains the existing reviewer path.

This is a conservative private-only guard, not a new approval or eligibility decision. It does not verify a reviewer-supplied date against the source, establish application availability, or enforce every historical decision's expiry. A worker-derived record that has already lost both its identifying snapshot reference and its identifying citation cannot be recognized by this guard. Before rollout, audit historical records and establish durable provenance for those cases. The safeguard does not prevent an independently created manual record from representing the same opportunity; duplicate handling and reviewer evidence remain separate concerns.
