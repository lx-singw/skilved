## User behavior

All five export controls stay disabled before hydration or without a validated server-injected origin. After mounting, native sharing is disabled when the method is absent and described as dependent on browser/apps when exposed; method presence does not establish a usable target. An explicit share action calls the existing fresh-read controller and text-only adapter. Unsupported/denied/ambiguous-abort feedback preserves the public preview, without automatic copy/download/app retries or recipient-delivery claims. A fresh asynchronous read can outlast native activation; that limitation is retained rather than bypassed.

WhatsApp compose uses a new fresh read for each explicit intent. Its deterministic builder accepts only the formatter's public text/canonical context, validates the exact HTTPS canonical opportunity path and creates a fixed https://wa.me/ URL with one URL-encoded text parameter, no selected recipient or application-added tracking fields. The [official click-to-chat help result](https://faq.whatsapp.com/5913398998672934) documents a recipient-free prefilled-message link; its opened page had no extractable body. The observed provider landing separately confirms the prefill behavior below. Provider redirects may add their own parameters outside this code.

The complete public text is used when the encoded navigation fits an 8000-character engineering budget. This is not a claimed WhatsApp platform limit. Long or unsupported text is replaced as a whole with its canonical public link; requirements/alternatives are never truncated. The full common public preview remains available for copy/download. Messages distinguish full text versus link-only compose and confirm neither app opening nor delivery. No state from ticks, saved stages, annotations, private receipt stores, page metadata or arbitrary caller URLs supplies the outgoing variant.

An owned temporary anchor requests current-tab navigation with no-referrer/noreferrer and is removed on success/failure. No popup, window opener, recipient picker, login or send is automated. The interface discloses that the draft request uses this tab and that the reader chooses a recipient and sends it themselves. Restricted/failed reads use the shared dated canonical-only reference, with no old title, instructions or official destination. Initial held/unavailable detail retains its safe page without export controls.
