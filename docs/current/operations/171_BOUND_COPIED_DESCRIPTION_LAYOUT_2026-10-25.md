25 October 2026. The RecentJobs parser now retains one recognised copied job-description wrapper inside its original WordPress notice. ## Narrow structural support

`recentjobs_html_copied_description_v1` applies only to one outer WordPress post containing exactly one additional non-post `article`. The outer post must agree with the canonical source URL, single-post body ID, outer ID/class, unique main container and outer title. These identity checks are shared with the existing bound-template parser; classic and bound-template outputs retain their existing adapter identities and fingerprints.

The nested article must have exactly the two recognised description-container classes, no other attributes, and no independent title, post header, publication time or additional article. It must be inside the single outer `entry-content`. Its sole content element is the recognised description div, whose sole content element is one uniquely identified `job-details` div with the expected content class. Only whitespace/comments may accompany those structural children. Unknown wrappers, extra body containers, sibling descriptions, independent notices, misplaced bodies and duplicate job-detail IDs remain explicit layout exceptions.

Parsing still reads the complete outer content. The introduction, conditions outside the copied wrapper, original application anchors, document instructions and competing dates/routes are retained. Scripts, forms, sharing and sidebars remain inert/excluded. No HTML snapshot is edited, wrapper removed, passage spliced or application URL rewritten. The adapter identity participates in the source fingerprint, and changes to conditions, date, introduction or route change that fingerprint.

Programme planning accepts this explicit new adapter while keeping its existing scoped-layout and evidence rules. Unknown adapter versions remain rejected. Model extraction/validation contracts, ordinary worker/publication gates, issuer registry and source-hold version are unchanged. Saved source exceptions are not reset or replayed automatically by this offline work.
