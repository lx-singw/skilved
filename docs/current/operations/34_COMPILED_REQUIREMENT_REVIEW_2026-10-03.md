## Implementation

`compiled-requirement-review.mjs` exposes diagnostic version `recentjobs_requirement_review_v3`. It reuses the V2 entry-applicability policy and historical whole-source evidence selectors without changing their behavior or request hashes. Source-derived post-selection, preparation, conditional-preference and audience uncertainty scopes, promotional lines and fully specified condition hints become code-owned passages. No employer name, frozen expectation or extracted claim determines ownership.

A narrow additional cue retains explicitly confirmed current application instructions requiring applicants' certified copies as mandatory document evidence. Optional, conditional and past-intake wording is not upgraded by this cue; existing uncertainty scopes take precedence. The complete source sentence remains verbatim, including any alternatives inside it. These rules express the current product interpretation, not independent proof of employers' screening policies.

The model receives the entire numbered source and the compiled passages for context. Its output contains only named remaining segments. Every segment key is required; passage spans are bounded to that segment. Local checks require an ordered, complete partition within every segment, then merge it with the code-owned passages. The model cannot overwrite, omit or echo a code-owned passage through this contract.

Current rows require non-null kind, strength, group and relation. All other rows contain only span and applicability, with no nullable metadata placeholders. Group 20 is reserved for independent code-owned ALL conditions; model groups use 1–19. Known alternative branches that intersect a proposed code-owned passage stop before spending rather than silently converting ANY to ALL. The shared compiler still enforces exact source evidence, classifications, alternatives, uncertainty and expression limits. Code supplies IDs, verbatim quotes and canonical logic.

Claims, gold inventories and application destinations are absent from the model payload. Inventories bind to source and contract hashes. Fully code-owned sources can compile without a model call, but still undergo canonical validation. Unknown evidence remains unknown; a supported comparison with retained uncertainty does not permit publication. The diagnostic covers verbatim requirements and their logic, not a complete opportunity's issuer, deadline, route or paraphrased semantic accuracy.
