# Qualification uncertainty and independent submission rules — 3 October 2026

The V6 development reviewer adds conservative source constraints for unclear qualification lists and independently stated current submission obligations. It also clarifies local kind/strength judgments in the blind review instruction. **All 254 catalogue tests passed.** Live regression and repeat results are recorded below; this experiment does not qualify autonomous publication.

## Source rules and model responsibility

`guarded-review-policy.mjs` introduces `entry_applicability_v3` on top of the unchanged bounded V2 policy. A consecutive run of plain qualifications in selected applicant evidence, with no explicit relationship, becomes one code-owned uncertain scope. Embedded Mathematics AND Science does not establish an AND between different qualifications. Known alternative branches, explicit ALL/OR cues, nested subject introductions, conditional wording and already constrained evidence do not acquire this new scope. An exact “All of the following” list introduction is context rather than an applicant condition; its qualification branches still compile as ALL. The rule preserves source uncertainty rather than choosing a relationship.

A narrow explicit current document-list introduction becomes context, with each recognized CV, certified ID and qualification/results copy compiled as an independent mandatory document condition. Recognized delivery and application-reference instructions also remain independent current submission obligations. Source text is retained verbatim. Code does not build an application destination from these requirements or turn enquiries into an application email.

Empty, alternative, conditional, optional, past and post-selection wording abstains. Existing uncertainty/future scopes take precedence, and a preceding caveat within the section also prevents current compilation. Lists exceeding ten recognized entries abstain. Unrecognized wording remains model-owned; these rules are not a universal document parser. The compiler still checks exact source spans, source constraints, complete alternatives, expression bounds and code/model ownership before accepting output.

`guarded-line-review.mjs` exposes `recentjobs_requirement_review_v6`. It keeps low reasoning, explicit JSON-object transport and strict local validation. The instruction adds an ordered applicability/kind/strength/group review, separates experience preferences from education and travel from general attributes, and keeps a preferred condition from changing adjacent plain profiles. Selection-test readiness is distinguished from previous-intake preparation, and recruitment pitch from independent gates. These judgments remain with the model outside the code-owned rules. No claimed condition or expected result is sent to the model.

The worker's separately named full V6 semantic validator is unchanged. This new V6 requirement reviewer is a development protocol, not worker adoption or a production setting.
