## Behavior and boundary

The server page wraps the existing public detail read in React request memoization and uses it for both the body and generateMetadata. Confirmed aliases therefore supply the returned canonical public ID. The page remains force-dynamic; no cross-request snapshot cache is introduced. The [official Next15 metadata documentation](https://nextjs.org/docs/15/app/api-reference/functions/generate-metadata) describes React cache for non-fetch reads, absolute titles and streamed metadata. Installed Next15.5.19 behavior is checked against actual local responses rather than inferred solely from the newer documentation.

A pure builder accepts only the strict public detail projection, an explicitly configured trusted HTTPS origin and a valid UTC check instant. Existing shared formatter eligibility decides whether current facts may appear. Active titles use a whole source-stated title up to 120 code points, otherwise the category. A modest description uses category and a whole source-stated issuer up to 80 code points, within 240 code points, followed by a reminder to read the current listing and original source because shared previews may be out of date. Controls, bidi markers and repeated whitespace are normalized; long fields are replaced as a whole. Next renders the text safely. Absolute titles avoid duplication by the root title template.

Closed, held, exact-expired or unavailable application instructions use generic metadata without former title/issuer facts. A valid known identity may retain its canonical reference; missing, failed, malformed, private-extra or untrusted-origin context cannot guess a URL. Date-only deadlines without time/zone do not acquire invented precision. The actual missing-page404 uses Next's safe root fallback, with no canonical/social URL. Existing noindex/nofollow remains in force.

Open Graph and Twitter summary fields share these modest strings; there are no images, eligibility/application/delivery claims or structured-data additions. Summaries, requirements, official application destinations, request headers/query strings, ticks/stages/annotations and private receipt state are outside the builder inputs. No deployed public hostname or indexing activation is established. External cached previews cannot be recalled by this change.
