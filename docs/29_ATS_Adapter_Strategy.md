# 29 ATS Adapter Strategy — current reference

Updated: 12 September 2026. The original hackathon document is preserved in the archive. This filename remains the entry point to its dedicated current successor.

## Current decision

Retain reusable platform adapters, source-to-issuer tracing, route detection, preparation, preflight and attributable receipts. The current strategy separates these capabilities from delegated submission and requires candidate identity, supported authority and duplicate-safe reconciliation for each enabled route.

Read the [full current ATS adapter strategy](current/engineering/03_ATS_ADAPTER_STRATEGY.md) for the original-plan disposition, registry/contracts, account model, failure handling, build stages, metrics and twelve acceptance scenarios. The [integration policy](current/engineering/02_INTEGRATION_AND_MIGRATION_POLICY.md) supplies broader integration rules. Proposed controls and features require implementation evidence before they are described as working.
