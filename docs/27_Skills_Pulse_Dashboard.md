## Why This Exists

South Africa spends R25 billion annually on skills development through SETAs. Allocation decisions are made based on surveys conducted 18 months ago. Thousands of learnerships expire unfilled every year while qualified candidates can't find them. The skills gap between supply and demand is invisible to everyone — government, employers, workers — because no one has ever had real-time, outcome-verified intelligence.

The Skills Pulse Dashboard changes this.

It is the first real-time national skills intelligence platform in South Africa, built entirely from verified outcome data generated by Skilved's agent network.

**It exists nowhere else on the African continent.**

## Agent 14: Skills Pulse Agent

### Job
Query the SA Skills Graph daily, synthesize national intelligence, and publish it to the Skills Pulse Dashboard. Generate government-grade intelligence reports monthly.

### Trigger
- Cloud Scheduler: daily at 2am SAST
- Admin trigger: on-demand
- Weekly: deeper analysis run (more compute-intensive queries)

### Core BigQuery Queries

**Demand-supply gap query:**
```sql
WITH demand AS (
  SELECT trade_category, province, COUNT(*) as open_opportunities
  FROM skilved_prod.opportunities
  WHERE status = 'active'
  GROUP BY trade_category, province
),
supply AS (
  SELECT primary_trade as trade_category, province,
    COUNT(*) as qualified_candidates
  FROM skilved_prod.users
  WHERE last_active_at > TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 30 DAY)
  GROUP BY primary_trade, province
)
SELECT
  d.trade_category,
  d.province,
  d.open_opportunities,
  COALESCE(s.qualified_candidates, 0) as qualified_candidates,
  d.open_opportunities - COALESCE(s.qualified_candidates, 0) as gap_score
FROM demand d
LEFT JOIN supply s USING (trade_category, province)
ORDER BY gap_score DESC
```

**Qualification ROI query:**
```sql
SELECT
  user_qualification,
  opp_trade,
  COUNT(*) as outcomes,
  AVG(opp_salary) as avg_salary_on_placement,
  AVG(days_to_placement) as avg_days_to_placement,
  COUNTIF(outcome_type = 'accepted') / COUNT(*) as placement_rate
FROM skilved_prod.outcomes
WHERE outcome_type IN ('accepted', 'offered', 'interviewed')
  AND DATE(outcome_at) >= DATE_SUB(CURRENT_DATE(), INTERVAL 90 DAY)
GROUP BY user_qualification, opp_trade
HAVING outcomes >= 10
ORDER BY avg_salary_on_placement DESC
```

## Dashboard UI Specification

### URL Structure
```
skilved.com/skills-pulse                → National overview
skilved.com/skills-pulse/electrical     → Trade-specific view
skilved.com/skills-pulse/gauteng        → Province-specific view
skilved.com/skills-pulse/report         → Monthly government report download
```

### Design Principles
- Data-first. Dense but legible.
- Mobile-first (trades workers on phones).
- Auto-updating without page reload (React Query polling).
- Every number has a "based on X data points" tooltip.
- Share buttons on every insight (WhatsApp, LinkedIn, Twitter).

### Key Components
```
<NationalOverview />           → Live counter cards
<DemandSupplyHeatmap />        → Province × Trade grid
<ExpiryRiskList />             → Learnerships at risk
<QualificationROIChart />      → Salary uplift by qualification
<TVETLeaderboard />            → College performance table
<PredictiveSignalCards />      → 6-month outlook
<IntelligenceNarrative />      → Gemini-generated insights
<GovernmentReportDownload />   → Monthly PDF
```

Auto-generated first of each month. Formatted for DHET, National Treasury, provincial skills offices.

2. National Skills Market Overview
